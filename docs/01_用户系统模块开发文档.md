## API清单

### 注册

POST /api/auth/register

请求：

```json
{
  "username":"test",
  "email":"test@example.com",
  "password":"123456"
}
```

### 登录

POST /api/auth/login

返回：

```json
{
  "token":"jwt-token"
}
```

### 获取当前用户

GET /api/users/me

### 修改资料

PUT /api/users/me
