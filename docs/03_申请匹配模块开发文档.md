# 03_申请匹配模块开发文档

## 模块负责人
成员C

## 模块职责
负责申请加入、审核申请、申请状态管理。

## 数据表

### applications
id
post_id
applicant_id
message
status
created_at

status:
pending
approved
rejected

## API

### 提交申请
POST /api/applications

### 我的申请
GET /api/applications/me

### 收到的申请
GET /api/posts/{id}/applications

### 审核申请
PUT /api/applications/{id}

## 页面

### 我的申请
- 待审核
- 已通过
- 已拒绝

### 审核页
- 申请人信息
- 申请理由
- 通过按钮
- 拒绝按钮

## 允许修改

frontend/src/pages/Applications

backend/app/api/application.py
backend/app/models/application.py
backend/app/schemas/application.py

## 禁止修改
users
posts
notifications

## 验收标准
- 可以提交申请
- 可以查看申请状态
- 发布者可审核申请
- 审核结果正确更新

## Claude Code提示词
实现申请与审核模块，遵守统一API格式与数据库规范。
