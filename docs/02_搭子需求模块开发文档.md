## API

### 创建需求
POST /api/posts

### 获取需求列表
GET /api/posts?page=1&keyword=&category=

### 获取需求详情
GET /api/posts/{id}

### 编辑需求
PUT /api/posts/{id}

### 删除需求
DELETE /api/posts/{id}
